# Abstract

**Project title:** Harvesta – AI-Powered Smart Agriculture Assistant
**Domain:** Artificial Intelligence, Machine Learning and Web Development
**Live website:** https://first-meeting-magic.lovable.app

Farmers often struggle to spot plant diseases early, find trusted crop-care advice, get quick answers to farming questions and check market prices. This information is spread across many sources.

Harvesta is a web application that brings these services together on one platform. **Leaf Analysis** lets a user upload a leaf photo; a vision-capable AI model describes visible symptoms, suggests possible diseases, pests or nutrient deficiencies with a confidence level, and recommends safe next steps. **AI Assistant** is a chatbot that answers questions about crops, pests, irrigation, soil and fertilisers, keeping chat history for the session. **Crop Care** builds a care plan from crop, soil type, growth stage and any described problem. **Mandi Prices** shows the official Minimum Support Prices (MSP) for this year and last year. A **Dashboard** and **About** page provide navigation and explain the project.

The site is built with React, TypeScript, TanStack Start and Tailwind CSS and runs on cloud hosting. AI requests go through a secure server so API keys never reach the browser. Every AI answer carries an uncertainty warning, and the site never shows invented prices.

**Keywords:** smart agriculture, plant disease detection, computer vision, AI chatbot, crop care, MSP
