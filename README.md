# Harvesta – AI-Powered Smart Agriculture Assistant

Live website: https://first-meeting-magic.lovable.app

Harvesta helps farmers keep crops healthy, all on one website:

- **Dashboard**: every feature at a glance.
- **Leaf Analysis**: upload a leaf photo to get possible diseases, a confidence level and safe next steps.
- **AI Assistant**: a farming chatbot for crops, pests, irrigation, soil and fertilisers.
- **Crop Care**: a care plan built from your crop, soil, growth stage and problem.
- **Mandi Prices**: official government Minimum Support Prices (MSP) for 21 crops, this year vs last year.
- **About**: the project's purpose, objectives and technology.

AI answers are guidance, not a guaranteed diagnosis. No price shown is ever invented.

## Built with
React 19, TypeScript, TanStack Start, Vite, Tailwind CSS, shadcn/ui, Vercel AI SDK, Lovable AI Gateway.

## Run locally
```sh
npm install
npm run dev
```
AI features need the `LOVABLE_API_KEY` environment variable.
